# Capsim Reports (GitHub Pages)

Student unlock site for Capsim coaching HTML reports.

- **Round menu (default):** Competition Round 3 (`reports/competition-round3/`)
- **Same menu:** Competition Round 2 (`reports/competition-round2/`, `?tab=round2`), Competition Round 1 (`?tab=competition`) (`reports/competition/`) and Practice Round Recap (`reports/practice/`)
- **Leaderboard:** public Round 1 Balanced Scorecard board at `leaderboard.html`. Data: `leaderboard-data.json` (firm names and roster display names only — no emails, usernames, or student numbers).
- Unlock with OrgDefinedId / student number (salted SHA-256 in `unlock.json` v4). Each entry may include `round3File`/`competitionRound3File` and `round2File`/`competitionRound2File` alongside the existing Round 1 and practice paths.

Live: https://thealiahmadi.github.io/capsim-reports/
